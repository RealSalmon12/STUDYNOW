# 공부 집중 잠금 (안드로이드 · 갤럭시 S25)

정한 시간 동안 폰을 잠그고, 허용한 앱과 전화만 쓸 수 있게 하는 앱입니다.

## 동작 방식
- **접근성 서비스**로 지금 어떤 앱이 열렸는지만 확인합니다 (화면 내용은 읽지 않음).
- 허용하지 않은 앱, 홈 화면, 최근 앱, **설정 앱**이 열리면 바로 잠금 화면으로 돌려보냅니다.
  설정이 막혀 있어서 잠금 중엔 접근성 권한을 끄거나 앱을 지울 수 없어요.
- 잠금 화면: 남은 시간, 허용 앱 아이콘, 긴급 전화 버튼. 뒤로 가기로 못 나갑니다.
- 전화·긴급통화·키보드는 항상 허용됩니다.
- 폰을 재부팅해도 접근성 서비스가 자동으로 다시 켜져서 **남은 시간부터** 잠금이 이어져요.
  (폰이 꺼져 있던 시간은 빠지지 않아요. 화면만 꺼진 시간은 정상적으로 흘러요.)

## 설치 방법
1. APK 파일을 폰으로 옮겨서 설치 ("출처를 알 수 없는 앱 설치" 허용)
2. 앱 실행 → 위쪽 "접근성 권한" 칸을 눌러 **설정 > 접근성 > 설치된 앱 > 공부 집중 잠금** 켜기
   - 스위치가 회색으로 안 켜지면: **설정 > 애플리케이션 > 공부 집중 잠금 > 오른쪽 위 ⋮ > 제한된 설정 허용** 을 먼저 누르세요.
3. 시간 고르고, 쓸 앱 체크하고, **잠금 시작**
4. 처음엔 **1분**으로 테스트해 보세요.

## APK 만드는 법
- **GitHub Actions**: 이 폴더를 GitHub 저장소에 올리면 Actions 탭에서 자동으로 APK가 만들어집니다 (Artifacts > FocusLock-apk).
- **Android Studio**: 이 폴더를 열고 Build > Build APK(s).

## 솔직한 한계
- 전원 버튼 길게 눌러 **안전 모드**로 재부팅하면 다른 앱이 다 꺼지므로 우회할 수 있어요.
- 접근성 **단축키**(볼륨 키 두 개 길게 누르기)를 이 앱에 지정해 두면 그걸로 끌 수 있으니, 단축키는 설정하지 마세요.
- 완전히 막으려면 Google Family Link 같은 보호자 관리가 가장 확실합니다.
