# 공부 집중 잠금 (Windows)

정한 시간 동안 컴퓨터 화면을 잠그고, 허용한 앱만 쓸 수 있게 하는 프로그램입니다.

## 실행 방법
1. [python.org](https://www.python.org/downloads/)에서 Python 설치 (설치 화면에서 "Add python.exe to PATH" 체크)
2. 이 폴더에서 `focus_lock.py` 더블클릭, 또는 `pythonw focus_lock.py`
3. (선택) `build_exe.bat` 을 실행하면 `dist\FocusLock.exe` 하나짜리 실행 파일이 생깁니다.

## 설정
- **잠금 시간**: 분 단위 (1~1440분)
- **허용 앱**: `이름 | 실행파일.exe | 실행 경로` 한 줄씩. 예)
  - `한글 | hwp.exe | C:\Program Files (x86)\HNC\Office 2022\HOffice120\Bin\Hwp.exe`
  - `인강 플레이어 | kollus.exe | C:\...\Kollus.exe`
  - 실행파일 이름은 작업 관리자 > 세부 정보 탭에서 확인할 수 있어요.
- **차단 앱**: 잠금 중 켜지면 바로 꺼질 앱 (브라우저, 게임, 카톡 등)

## 잠금 중 막히는 것
- 모든 모니터를 덮는 잠금 화면, 닫기·Alt+F4 무시
- 허용 안 된 창이 앞으로 오면 내려버리고 잠금 화면이 다시 덮음
- 작업 관리자, 명령 프롬프트, PowerShell, 레지스트리 편집기, 설정 앱 자동 종료
- 잠금 창을 강제로 꺼도 감시 프로세스가 1초 안에 다시 띄움
- 로그아웃하거나 재부팅해도 로그인하면 **남은 시간부터** 다시 잠김
- 잠금이 켜져 있는 동안에만 시간이 줄어서, 시계를 바꾸거나 컴퓨터를 꺼서 시간을 흘려보낼 수 없음

## 솔직한 한계
- 전원 버튼으로 끄고 **안전 모드**로 부팅하거나, 다른 관리자 계정으로 로그인하면 우회할 수 있어요. 완전히 막으려면 공부용 계정을 '표준 사용자'로 만들고 관리자 비밀번호를 부모님 등 다른 사람이 갖고 있는 게 가장 확실합니다.
- 브라우저를 허용 앱에 넣으면 그 브라우저로는 아무 사이트나 들어갈 수 있어요.
- Windows 10/11 전용입니다. 맥은 따로 만들어야 해요.
