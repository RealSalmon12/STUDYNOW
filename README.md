# STUDYNOW · 공부 집중 잠금

정한 시간 동안 컴퓨터와 폰을 잠그고, 허용한 앱만 쓸 수 있게 하는 프로그램입니다.

| 폴더 | 내용 |
|---|---|
| [`windows/`](windows/) | Windows 10/11용 잠금 프로그램 (Python) |
| [`android/`](android/) | 안드로이드(갤럭시 S25 등)용 잠금 앱 (Kotlin) |

## 설치 파일 받기
GitHub의 **Actions** 탭 → 가장 최근 "Build apps" 실행 → 아래쪽 **Artifacts**에서
- `FocusLock-android-apk` : 폰에 설치할 APK
- `FocusLock-windows-exe` : 컴퓨터에서 실행할 FocusLock.exe

자세한 사용법과 한계는 각 폴더의 README를 보세요.
